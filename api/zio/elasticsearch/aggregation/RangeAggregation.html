  3.  abstract def withSubAgg(subAgg: SingleElasticAggregation): RangeAggregation

    Adds a sub-aggregation to the aggregation.

    Adds a sub-aggregation to the aggregation. Sub-aggregations are kept in the order in which they are added and must have unique names.

    A zio.elasticsearch.aggregation.MultiBucketAggregation accepts any zio.elasticsearch.aggregation.SingleElasticAggregation, while a zio.elasticsearch.aggregation.SingleBucketAggregation accepts any zio.elasticsearch.aggregation.ElasticAggregation, since parent pipeline aggregations require a multi-bucket parent.

    subAgg

    the aggregation to add as sub-aggregation

    returns

    a new instance of the zio.elasticsearch.aggregation.BucketAggregation with the given sub-aggregation.
